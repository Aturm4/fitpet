# FitPet

Камерная фитнес-игра: пользователь выполняет упражнения перед камерой, а персонаж получает опыт, меняет форму и развивается вместе с ним.

## Что реализовано

- распознавание позы через MediaPipe;
- подсчёт приседаний, отжиманий и jumping jacks;
- система XP, уровней и визуальных стадий персонажа;
- дневные цели, серии тренировок и потеря XP за пропуски;
- локальное сохранение прогресса;
- адаптивный интерфейс тренировки и статистики.

## Стек

`React 19` · `TypeScript` · `Vite` · `MediaPipe Pose` · `Zustand` · `PixiJS` · `Tailwind CSS`

## Запуск

```bash
npm install
npm run dev
```

Для распознавания упражнений браузеру потребуется доступ к камере.

## Проверка

```bash
npm run lint
npm run build
```

## Статус

Рабочий прототип. Дальше планируется улучшить устойчивость распознавания, добавить больше упражнений и расширить прогрессию персонажа.
